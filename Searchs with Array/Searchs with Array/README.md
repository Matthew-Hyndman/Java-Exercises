# Searches with Array

## Linear Search
Linear search is a simple search algorithm that checks every element in an array sequentially until the desired element is found or the end of the array is reached. It has a time complexity of O(n), where n is the number of elements in the array.

## Binary Search
Binary search is a more efficient search algorithm that works on sorted arrays. It repeatedly divides the search interval in half, comparing the target value to the middle element of the array. If the target value is equal to the middle element, the search is successful. If the target value is less than the middle element, the search continues in the lower half of the array, otherwise, it continues in the upper half. Binary search has a time complexity of O(log n).
